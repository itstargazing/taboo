# Project Finder for Passion Projects

A web application that helps students discover original, non-cliché project ideas based on their unique personalities, passions, and hidden talents.

## Features

- Interactive quiz to discover personal interests and skills
- AI-powered project idea generation
- Project idea library and exploration
- Personal project vault for saved ideas
- Clean, minimalistic design with smooth animations

## Tech Stack

- React with TypeScript
- Tailwind CSS for styling
- Framer Motion for animations
- React Router for navigation

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Project Structure

- `src/pages/` - Main page components
- `src/components/` - Reusable UI components
- `src/styles/` - Global styles and Tailwind configuration
- `src/types/` - TypeScript type definitions
